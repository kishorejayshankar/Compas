# Compass Marketing Analytics

A responsive marketing analytics consulting website for Compass.

## Positioning
Compass helps businesses turn marketing data into clear direction, measurable growth, and confident decisions.

## Website
The site is a static `index.html` designed for GitHub Pages.

## GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Services
- Performance Analytics
- Customer & Funnel Insights
- Growth Strategy
- Measurement and reporting systems
